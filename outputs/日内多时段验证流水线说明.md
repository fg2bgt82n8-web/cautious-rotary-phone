# 日内多时段验证流水线说明

本文件定义「日内多时段验证」流水线的各时段规格。流水线以 A 股交易日为驱动，按时间顺序依次执行盘前推荐 → 早盘跟踪 → 午盘复盘 → 盘后验证 → 收盘总结。各环节相互衔接，上一环节的输出（推荐股票 + 参考买点/止损）写入台账，供后续环节读取。

## 通用约定

- **交易日校验**：先核验当天是否为 A 股交易日（依据沪深北交易所年度休市安排与周末）。非交易日则输出「今日休市」并结束本日流水线。
- **数据源**：通达信（tdx_quotes）等行情接口；取不到的数据统一标「数据缺失」，不编造。
- **输出**：每一环节产出自包含 HTML 到 `/workspace/outputs/`，命名带日期与时间戳（如 `午盘复盘-YYYYMMDD-1135.html`）。
- **台账**：所有环节的个股动线统一追加写 `/workspace/outputs/推荐与验证台账.csv`，追加字段含环节、时间、股票代码、现价、涨跌幅、成交额、结论等。
- **阶段指示器**：HTML 顶部阶段指示器标记当前时段为 `active`，其余时段为历史/未来状态。

## 时段规格

### 1. 盘前推荐（约 09:15，开盘前）
- 交易日校验；读取消息面、宏观/行业催化，生成当日候选股池。
- 为每只候选给定代码、名称、参考买点区间（下限/上限，取中值为买入价基准）、止损价，写入台账（环节=盘前推荐）。
- 产出 `盘前推荐-YYYYMMDD-0915.html`（含阶段指示器盘前 active、推荐列表、免责声明）。

> 状态：本会话尚未运行，规格待实际实施时补充量化取数细节。

### 2. 早盘跟踪（约 10:00 或 10:30，上午盘中）
- 读取台账中盘前推荐股池 + 新增股代码。
- 采集盘中报价，对照参考买点判定触发买点/止损，给出早盘强弱与操作建议。
- 追加台账（环节=早盘跟踪），产出 `早盘跟踪-YYYYMMDD-1000.html`。

> 状态：本会话尚未运行，规格待实际实施时补充量化取数细节。

### 3. 午盘复盘（11:35，上午收盘后）★ 本环节为核心规格
1. **交易日校验**：非 A 股交易日输出「今日休市」并结束。
2. 读取本说明了解各时段规格。
3. 读取 `/workspace/outputs/推荐与验证台账.csv`：取今日盘前推荐 + 早盘跟踪的 10 股 + 新增股代码。若无记录，输出「今日无盘前推荐，跳过」并结束。
4. **数据采集**（tdx_quotes）：取各股上午收盘价、半日涨跌幅、半日成交额、量能对比（vs 昨日全天）；同时取上证/深成/创业板半日表现。取不到标「数据缺失」。
5. **半日表现汇总**：各股半日涨跌幅、成交额、量能对比、持仓盈亏估算（买入价＝参考买点中值 → 算盈亏%）、触发买点/止损统计。
6. **午盘策略调整**：上午强势/弱势判断；下午操作重点（加仓/减仓/观望/止损）；仓位调整建议（上调/下调/维持）。
7. **下午关注点**：重要数据/事件、关键价位。
8. **产出 HTML** `/workspace/outputs/午盘复盘-YYYYMMDD-1135.html`（参考日内验证 HTML 模板，阶段指示器标记「午盘 11:35」为 active，含盈亏统计区块）：半日汇总表 → 盈亏统计 → 策略调整 → 下午关注 → 免责声明。
9. **台账追加**：环节=午盘复盘，时间=1135，更新现价/涨跌幅/成交额/结论。
10. 完成后用 OpenPreview 展示 HTML。

### 4. 盘后验证（约 15:10，收盘后）
- 采集全天数据，回测当日推荐买卖点命中与收益率，验证策略逻辑。
- 追加台账并产出 `盘后验证-YYYYMMDD-1510.html`。

### 5. 收盘总结（约 15:30）
- 汇总全日盈亏、胜率、触发统计，形成当日结论。
- 追加台账并产出 `收盘总结-YYYYMMDD-1530.html`。
