# 日内多时段验证流水线说明

> 基于「欧奈尔CANSLIM本土化 + 楔形理论 + 顶底山峰」策略框架
> 适用于 A+H 全市场盘前十股推荐的日内跟踪验证
> 生效日期：2026-09-23
> 文件路径：/workspace/outputs/

---

## 第一节 时间段划分

| 时段 | 触发时间 | 环节名称 | 核心任务 |
|------|---------|---------|---------|
| 1 | 08:30 | 盘前推荐 | M否决+CANSLIM选股+产出十股HTML+台账 |
| 2 | 09:35 | 开盘验证 | 验证10股开盘表现+触及买点/止损+开盘情绪 |
| 3 | 10:30 | 早盘跟踪 | 10股实时表现+盘中新增1-2支机会+板块轮动 |
| 4 | 11:35 | 午盘复盘 | 半日汇总+午盘策略调整+下午关注点 |

- 各时段独立产出HTML，文件名格式：`{环节名}-{YYYYMMDD}-{HHMM}.html`
- 台账CSV逐时段追加，环节列填对应名称

## 第二节 各时段方法规格

### 时段1：盘前推荐 (08:30)
**完整执行盘前十股推荐流水线（详见已有规格）**
- 交易日校验 → 数据采集(昨日盘口+隔夜外股+五日情绪) → M大盘否决 → CANSLIM七要素+楔形+顶底山峰选股 → A股5支+港股5支 → HTML → 台账
- 输出：`盘前推荐-{YYYYMMDD}.html`
- 台账环节：盘前推荐

### 时段2：开盘验证 (09:35)
**验证盘前10股开盘表现**
1. 读取当日盘前推荐HTML/台账，获取10股代码列表
2. 数据采集（tdx_quotes实时行情，开盘后5分钟）：
   - 10股开盘价、现价、涨跌幅、集合竞价量、量比
   - 是否一字涨停（无法买入，标注"封死"）/一字跌停
   - 是否高开/低开/平开，开盘方向
3. 买点验证：
   - 现价是否进入参考买点区间 → 标注"买点触发/未触发/已超买点"
   - 是否触及止损位 → 标注"止损预警"
4. 开盘情绪快评：上证/深成开盘方向、涨跌家数、涨停家数 → 0-10分
5. 产出HTML：开盘验证卡片（10股开盘表现表+触发状态+情绪快评+操作提示）
6. 台账追加：环节=开盘验证，更新现价/涨跌幅/量比/成交额/结论
- 输出：`开盘验证-{YYYYMMDD}-0935.html`

### 时段3：早盘跟踪 (10:30)
**盘中实时跟踪+新增机会**
1. 读取10股（盘前推荐）+ 前序新增股实时行情（tdx_quotes）
2. 10股表现跟踪：
   - 涨跌幅、量比、成交额、是否突破关键位/回踩MA
   - 楔形/顶底山峰形态实时状态（是否放量突破/缩量回踩）
   - 加减仓信号：突破放量=加仓信号、跌破MA20=减仓预警
3. 盘中新增（1-2支）：
   - 基于早盘强势板块 + CANSLIM快筛 + 楔形买点触发
   - 从tdx_screener（放量突破/MACD金叉）获取候选
   - 新增股标注"盘中新增"，计入跟踪列表
4. 板块轮动观察：早盘强势/弱势板块TOP5
5. 产出HTML：早盘跟踪卡片（10+新增股表现表+信号状态+板块轮动+操作建议）
6. 台账追加：环节=早盘跟踪
- 输出：`早盘跟踪-{YYYYMMDD}-1030.html`

### 时段4：午盘复盘 (11:35)
**半日汇总+策略调整**
1. 读取10股+新增股上午收盘行情
2. 半日表现汇总：
   - 各股半日涨跌幅、成交额、量能对比（vs昨日全天）
   - 持仓盈亏估算（相对参考买点）
   - 触发买点/止损统计
3. 午盘策略调整：
   - 上午强势/弱势判断
   - 下午操作重点（哪些股加仓/减仓/观望/止损）
   - 仓位调整建议（总仓位上调/下调/维持）
4. 下午关注点：重要数据/事件、关键价位
5. 产出HTML：午盘复盘卡片（半日汇总表+盈亏估算+策略调整+下午关注）
6. 台账追加：环节=午盘复盘
- 输出：`午盘复盘-{YYYYMMDD}-1135.html`

### 时段5：尾盘决策 (14:30)
**收盘前操作决策**
1. 读取10股+新增股尾盘行情
2. 尾盘表现：
   - 涨跌幅、量比、尾盘资金流向
   - 是否尾盘拉升/跳水
3. 操作决策（逐股）：
   - **加仓**：形态确认+量能配合+未超买
   - **减仓**：涨幅过大+量能背离+接近压力位
   - **止损**：跌破止损位或形态破坏
   - **持有**：走势正常+未触发信号
   - **卖出**：达到目标价或趋势走弱
4. 收盘前最后操作建议：明确每支股的操作+价位
5. 产出HTML：尾盘决策卡片（逐股操作决策表+价位+仓位调整）
6. 台账追加：环节=尾盘决策
- 输出：`尾盘决策-{YYYYMMDD}-1430.html`

### 时段6：盘后复盘 (15:05)
**全日验证+盈亏统计+次日展望**
1. 读取10股+新增股收盘行情
2. 全日表现验证：
   - 收盘价、全日涨跌幅、成交额、换手率
   - 相对参考买点盈亏%（买入假设价=参考买点中值）
   - 形态验证：楔形突破是否成功、顶底山峰是否成立
3. 盈亏统计：
   - 10股+新增平均盈亏%、胜率（盈利股数/总股数）
   - 最佳/最差表现股
4. 台账完整更新：补全收盘数据、盈亏、结论
5. 次日展望：
   - 明日关注要点（关键价位、形态演变、板块趋势）
   - 是否调整推荐名单（剔除走弱/新增机会）
6. 产出HTML：盘后复盘卡片（全日验证表+盈亏统计+次日展望）
7. 台账追加：环节=盘后复盘
- 输出：`盘后复盘-{YYYYMMDD}-1505.html`

## 第三节 数据约束

### 数据源优先级
1. **tdx_quotes / tdx_kline / tdx_screener**（通达信MCP，实时行情+K线+选股）— 首选
2. **wenda_news_query**（资讯查询）— 盘口/板块/收评
3. **WebSearch**（兜底）— 仅指数与收评

### 防虚构规则
- 取不到的数据标"数据缺失"，禁止编造
- 实时行情以tdx_quotes为准，标注数据时间
- 盘后数据以收盘为准

### 请求间隔
- tdx_quotes批量查询间隔≥1.2s，防429
- tdx_screener单次查询，结果缓存复用

## 第四节 台账格式

CSV文件：`/workspace/outputs/推荐与验证台账.csv`（utf-8-sig）

列定义：
```
日期,环节,时间,代码,名称,市场,CANSLIM评分,买点形态,信号,参考买点(元),现价(元),涨跌幅%,量比,成交额(万),主力净流入(万),结论,备注
```

- 日期：YYYYMMDD
- 环节：盘前推荐/开盘验证/早盘跟踪/午盘复盘/尾盘决策/盘后复盘
- 时间：HHMM
- 市场：沪A/深A/创业板/科创板/港股通
- 各时段追加同一批次，现价/涨跌幅等按当时实时数据更新

## 第五节 HTML输出规范

- 自包含HTML（内联CSS/JS，Chart.js可走CDN）
- 文件名全中文：`{环节名}-{YYYYMMDD}-{HHMM}.html`（盘前推荐无HHMM后缀）
- 统一深色主题（与盘前推荐HTML风格一致）
- 必含：时段标题卡片 → 数据摘要 → 股票表现/决策卡片 → 板块/风险 → 免责声明
- 免责声明："AI基于公开数据自动生成，仅供研究参考，不构成投资建议"
